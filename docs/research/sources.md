## Prior Art: MTG/CCG Draft AI

- [AI solutions for drafting in Magic: the Gathering (Ward et al., IEEE CoG 2021)](https://arxiv.org/abs/2009.00655) *(paper)* — verify: reachable✅, accurate✅  
  Released ~107,949 Draftsim human drafts; NNetBot (512-neuron dense layers + dropout, softmax over N one-hot cards, cross-entropy) won at 48.67% mean per-pick accuracy / 1.48 pick distance vs DraftsimBot 44.54% and BayesBot 43.36%. One-hot cards => no unseen-card generalization (noted as future work).
- [Teaching an AI to Draft Magic: the Gathering (Zachary Witten, TDS/Medium)](https://medium.com/data-science/teaching-an-ai-to-draft-magic-the-gathering-ba38b6a3d1f3) *(blog)* — verify: reachable✅, accurate✅  
  Concrete Draftsim-style architecture: input = 2N vector (pack one-hot + collection counts), 512-neuron dense layers with dropout, N-way softmax, one-hot human-pick target; 59% accuracy vs 50% linear baseline. Discusses (but does not implement) MTGJSON features for new-set generalization.
- [Predicting Human Card Selection in MtG with Contextual Preference Ranking (Bertram, Fürnkranz, Müller, IEEE CoG 2021)](https://arxiv.org/abs/2105.11864) *(paper)* — verify: reachable✅, accurate✅  
  Siamese network trained on (context, chosen, rejected) triplets; CPR learns an embedding where chosen cards sit closer to deck context. >56% relative accuracy gain and >83% lower pick distance vs Draftsim NN. Original version still one-hot (fixed card set).
- [Learning With Generalised Card Representations for Magic: The Gathering (Bertram, Fürnkranz, Müller, IEEE CoG 2024)](https://arxiv.org/abs/2407.05879) *(paper)* — verify: reachable✅, accurate✅  
  Most relevant to unseen-card generalization: replaces one-hot IDs with numeric/nominal features, card-text, name, image, and meta embeddings; ~55% accuracy on completely unseen cards. Representation choice barely affects known cards but greatly improves new cards. Best-paper nominee.
- [UrzaGPT: LoRA-Tuned LLMs for Card Selection in CCGs (2025)](https://arxiv.org/abs/2508.08382) *(paper)* — verify: reachable✅, accurate✅  
  LoRA fine-tunes (Llama-3-8B, Mistral-7B) on ~1M 17lands NEO picks; cards by name only in NL prompts; best 66.2% (Llama-3-8B), Mistral 64.3%, GPT-4o zero-shot 43%, cited SOTA ~68%. Cross-set generalization asserted plausible but explicitly untested (restricted to NEO).
- [Statistical Drafting - About](https://statisticaldrafting.com/about) *(docs)* — verify: reachable✅, accurate✅  
  PyTorch MLP: collection + pack vectors -> per-card ratings, pack vector as mask; BatchNorm/dropout/exp-decay LR; trained on 17lands high-skill players; ~70% agreement with top-player picks; per-set retraining, no cross-set generalization.
- [khakhalin/MTG - Draftsim paper bots and embeddings (GitHub)](https://github.com/khakhalin/MTG) *(repo)* — verify: reachable✅, accurate✅  
  Official Draftsim code: RandomBot/RaredraftBot/DraftsimBot/BayesBot/NNetBot, Draftsim data standardization + CV pipeline, MDS scaling on co-drafting distances as exploratory card embeddings.
- [madrury/mtg-draftbot - Algorithmic Drafting for MtG (GitHub)](https://github.com/madrury/mtg-draftbot) *(repo)* — verify: reachable✅, accurate✅  
  Interpretable bilinear archetype-weight model (held-cards @ archetype_weights, softmax, NLLLoss); no hidden layers/attention/learned embeddings; demonstrated on simulated drafts; no unseen-card generalization.
- [Official CubeCobra DraftBot Primer (Parts 1-2)](https://cubecobra.com/content/article/6008b17565264010480a4a84) *(blog)* — verify: reachable✅, accurate✅  
  Per CubeCobra docs, draftbot encodes pool to a 128-dim embedding + 32-dim cube-context => 160-dim decoder input scoring each pack card; trained on hundreds of thousands of human picks; earlier 'oracles + learned time-varying weights' design; must handle arbitrary/custom cube cards.
- [Contrastive Learning of Preferences with a Contextual InfoNCE Loss (arXiv:2407.05898)](https://arxiv.org/abs/2407.05898) *(paper)* — verify: reachable✅, accurate✅  
  Companion/methodological work extending CPR to a contextual InfoNCE (multi-candidate contrastive) loss for preference ranking; relevant to scaling Siamese preference learning beyond single triplets. PDF body not text-extractable; details taken from search-surfaced abstract, treat numbers cautiously.

## Card Representation for Generalization

- [Learning With Generalised Card Representations for Magic: The Gathering (Saxton, 2024, arXiv:2407.05879)](https://arxiv.org/abs/2407.05879) *(paper)* — verify: reachable✅, accurate✅  
  Directly studies generalization to unseen MTG cards. Compares random vectors, hand-coded numeric/categorical features, Sentence-BERT oracle-text embeddings, conv-autoencoder image features, and usage meta-features. Combined content representation reaches ~42.9% unseen-card accuracy trained on one set and ~55.4% on a ~100M-decision corpus (random ~22%); one-hot ID encodings cannot generalize and would need a new model per set. Representation choice barely affects seen-card accuracy but greatly improves unseen-card accuracy.
- [AI solutions for drafting in Magic: the Gathering (Ward et al., 2020, arXiv:2009.00655)](https://arxiv.org/abs/2009.00655) *(paper)* — verify: reachable✅, accurate✅  
  Original DraftSim/NNet draft-pick work; encodes the collection as a bag-of-cards count vector indexed by card identity (length = set size, e.g. 265 for M19) with dense layers sized to that vocabulary. Analyses are single-set only and the authors flag generalization to diverse sets / unseen cards as future work — illustrating the ID-vocabulary cold-start limitation.
- [Predicting Human Card Selection in MTG with Contextual Preference Ranking (Bertram et al., 2021, arXiv:2105.11864)](https://arxiv.org/abs/2105.11864) *(paper)* — verify: reachable✅, accurate✅  
  Siamese network learns a card embedding space by comparing cards in deck context; embedding dimension matters up to ~D=32 with diminishing returns by D=128. Shows the embedding-space framing for picks but still operates over a known card set.
- [beeFormer: Bridging the Gap Between Semantic and Interaction Similarity in Recommender Systems (RecSys 2024, arXiv:2409.10309)](https://arxiv.org/abs/2409.10309) *(paper)* — verify: reachable✅, accurate✅  
  Trains sentence transformers on interaction data so text embeddings reflect behavioral similarity, enabling cold-start/zero-shot recommendation from item text and cross-domain transfer; outperforms both frozen semantic embeddings and traditional CF. Key insight for making oracle-text embeddings gameplay-aware while retaining zero-shot generalization.
- [Language-Model Prior Overcomes Cold-Start Items (arXiv:2411.09065)](https://arxiv.org/abs/2411.09065) *(paper)* — verify: reachable✅, accurate✅  
  Uses LLM-derived text priors to overcome cold-start items, fusing content/text signal with collaborative embeddings so new items inherit structure from warm items. NOTE: I could not fully extract the PDF body (binary stream), so specifics of its fusion architecture and exact gain numbers are reported only from the title/search-level abstract, not verified line-by-line.
- [Zero-shot Item-based Recommendation via Multi-task Product Knowledge Graph Pre-Training (arXiv:2305.07633)](https://arxiv.org/abs/2305.07633) *(paper)* — verify: reachable✅, accurate✅  
  Frames the zero-shot item problem as inferring item embeddings from generic side-information (titles/descriptions) using pretrained LMs — the same principle that makes oracle-text encoding the route to representing never-seen cards. Found via search; abstract-level only, PDF body not fetched.
- [Scryfall API — Card object, fields, and Bulk Data](https://scryfall.com/docs/api/bulk-data) *(docs)* — verify: reachable✅, accurate✅  
  Likely attribute source: Card objects expose mana_cost, cmc, colors, color_identity, type_line, oracle_text, power, toughness, keywords, loyalty, rarity, produced_mana, and image_uris; oracle_text is the official, reprint-consistent rules text. Bulk files (Oracle Cards / Default Cards / All Cards) provide every gameplay field for every card, refreshed ~every 12 hours. NOTE: scryfall.com/docs pages returned HTTP 403 to my fetcher; field names/behavior are confirmed from Scryfall's own search-result snippets, not a full page fetch.

## Set-Based Architectures & Pick Heads

- [Deep Sets (Zaheer et al., NeurIPS 2017)](https://arxiv.org/abs/1703.06114) *(paper)* — verify: reachable✅, accurate✅  
  Permutation-invariant functions decompose as f(X)=rho(sum_i phi(x_i)); gives universal-approximation characterization and the tied-weight equivariant layer Theta=lambda*I+gamma*(1 1^T). Foundation for encoding the picked-card pool; sum pooling is a bottleneck that misses pairwise synergy.
- [Set Transformer: Attention-based Permutation-Invariant Neural Networks (Lee et al.)](https://arxiv.org/pdf/1810.00825) *(paper)* — verify: reachable✅, accurate✅  
  Introduces SAB (self-attention among set elements), ISAB (inducing points, O(n*m) cost) and PMA (learned attention pooling with seed vectors). Attention pooling captures inter-element relationships that sum pooling loses — directly useful for modeling card synergy within the pool and scoring within the pack.
- [Pointer Networks (Vinyals, Fortunato, Jaitly, NeurIPS 2015)](https://arxiv.org/pdf/1506.03134) *(paper)* — verify: reachable✅, accurate✅  
  Uses content-based attention as a POINTER: output is a softmax over input positions whose size equals the variable input length. This is the canonical way to produce a probability distribution over a variable candidate set (the pack) instead of a fixed-vocabulary softmax.
- [Predicting Human Card Selection in MTG with Contextual Preference Ranking (Bertram et al.)](https://arxiv.org/abs/2105.11864) *(paper)* — verify: reachable✅, accurate✅  
  Models draft by embedding the deck/pool context and a card jointly and learning preferences with triplet loss; evaluates a card in the CONTEXT of already-selected cards. Direct MTG instantiation of a set-context + candidate-scoring architecture.
- [Contrastive Learning of Preferences with a Contextual InfoNCE Loss (Bertram et al.)](https://arxiv.org/abs/2407.05898) *(paper)* — verify: reachable✅, accurate✅  
  Adapts InfoNCE so one positive card is contrasted against the SET of other pack cards in one batch term — a learned variable-width softmax over candidates; reported to outperform triplet loss and avoid triplet mining. Maps exactly to 'pick one card preferred over the rest of the pack.'
- [Learning With Generalised Card Representations for Magic: The Gathering (Bertram et al.)](https://arxiv.org/abs/2407.05879) *(paper)* — verify: reachable✅, accurate✅  
  Replacing per-card ID embeddings with feature-based representations (numeric/nominal stats, card-text embeddings, images, meta usage) barely changes accuracy on KNOWN cards but raises accuracy on UNSEEN cards to ~55%. This is the key to generalization beyond the training card set.
- [AI solutions for drafting in Magic: the Gathering (Ward et al., Draftsim)](https://arxiv.org/pdf/2009.00655) *(paper)* — verify: reachable✅, accurate✅  
  NNetBot: MLP over a collection vector (pool) and pack vector outputs a per-card rating; was the strongest bot at predicting human picks. Establishes the fixed-vector + pack-mask baseline (a Deep-Sets special case) and its per-set retraining limitation.
- [Statistical Drafting — About (production MTG draft helper)](https://statisticaldrafting.com/about) *(blog)* — verify: reachable✅, accurate✅  
  Production MLP trained on 17lands: collection vector + pack vector -> 0-100 card ratings, pack vector masks non-pack cards (ones vector at inference), BatchNorm/dropout, ~70% agreement with top players, ONNX in-browser. Concrete reference for the masked fixed-head pattern.

## Training Objectives & Learning Signals

- [AI solutions for drafting in Magic: the Gathering (Ward, Mills, Brooks, Khakhalin, Troha; IEEE CoG 2021)](https://arxiv.org/pdf/2009.00655) *(paper)* — verify: reachable✅, accurate✅  
  Frames drafting as masked multi-class classification; NNetBot (deep NN, cross-entropy, 20 epochs, pack-masked argmax) gets 48.67% top-1 vs 44.54% expert heuristic and 22% random over 107,949 human drafts. Notes imitation goal is human-likeness not objectively-best picks, and that imitation bots mis-handle 'raredrafting' (a conformity artifact). Releases the first large public draft dataset.
- [Predicting Human Card Selection in MTG with Contextual Preference Ranking (Bertram, Fuernkranz, Mueller; IEEE CoG 2021)](https://arxiv.org/pdf/2105.11864) *(paper)* — verify: reachable✅, accurate✅  
  Siamese network + triplet loss with pool=anchor, picked=positive, unpicked=negative; distance-to-empty-set gives a card power ranking. Beats classification baseline (53.69% even at D=2, up to ~64%; >56% relative accuracy gain, >83% lower pick distance). Captures synergy/context; positive examples skew toward strong cards so weak-card weakness is under-learned.
- [Contrastive Learning of Preferences with a Contextual InfoNCE Loss (Bertram, Fuernkranz, Mueller; 2024)](https://arxiv.org/pdf/2407.05898) *(paper)* — verify: reachable✅, accurate✅  
  Adapts CLIP/InfoNCE to contextual preference ranking via a masked, row-wise cross-entropy over in-pack cards; outperforms triplet loss and vanilla CLIP while removing triplet mining (~10% overhead). Uses 17lands human-selection data. States no strong full-game self-play MTG agent exists yet, and that encoding context INTO the loss remains open.
- [Bot Drafting the Hard Way: A New Drafting Model (Ryan Saxe, Draftsim)](https://draftsim.com/ryan-saxe-bot-model/) *(blog)* — verify: reachable✅, accurate✅  
  Rejects rote behavior cloning; uses mathematical priors (per-archetype linear models via K-means clustering, archetypal bias weighting, 'staying open decays over time'). Beats the data: ~91% on a P3P1 where humans are ~80% correct - a concrete example of producing better-than-human, debiased picks.
- [RyanSaxe/mtg: State of the Art MTG Draft and DeckBuilder AI (GitHub)](https://github.com/RyanSaxe/mtg) *(repo)* — verify: reachable✅, accurate✅  
  Transformer-based draft AI plus a deckbuilder; reports reaching Mythic rank at ~66% win rate over 23 drafts, claimed first AI to do so. Illustrates the self-play/closing-the-loop direction (need a deckbuilder + game agent to turn picks into win-rate reward). README does not disclose the exact loss; train-it-yourself.
- [Statistical Drafting - About (statisticaldrafting.com)](https://statisticaldrafting.com/about) *(blog)* — verify: reachable✅, accurate✅  
  Small PyTorch MLP (BatchNorm, dropout, decaying LR) takes collection+pack vectors, outputs ratings, pack used as a mask to zero out unavailable cards. Trained on 17lands data FILTERED to high-volume high-win-rate players (~70% agreement with top players) - a concrete win-rate-filtered imitation pipeline to reduce conformity bias.
- [Using Win Rate Data (17Lands Blog)](https://blog.17lands.com/posts/using-win-rate-data/) *(blog)* — verify: reachable✅, accurate✅  
  Defines GP WR (about half noise from games where the card wasn't drawn), OH WR, GD WR, GIH WR (drawn at any point, least biased, no need to cast). Caveats: GIH WR biases toward controlling decks (longer games) and confounds deck/archetype quality; treat WR as a starting point, strongest signal early in a draft.
- [Knowledge and Power: Estimating Adjusted Win Rate in MTG Limited (mtgds)](https://mtgds.wordpress.com/2022/02/28/knowledge-and-power-estimating-adjusted-win-rate-in-magic-the-gathering-limited/) *(blog)* — verify: reachable✅, accurate✅  
  Proposes Adjusted Win Rate via linear regression controlling for other cards in the deck, pairwise synergy, on-the-play, mulligans and player win rate, isolating each card's marginal contribution. Documents co-occurrence/deck-quality confounding in GP WR and game-length bias in GIH WR - the case for confounder-adjusted labels over raw 17lands aggregates.

## Transferable Techniques from Adjacent Domains

- [Learning With Generalised Card Representations for Magic: The Gathering (Bertram et al., 2024)](https://arxiv.org/pdf/2407.05879) *(paper)* — verify: reachable✅, accurate✅  
  Replaces card-ID embeddings with content features (numeric/nominal, sentence-transformer text, conv-autoencoder image, meta usage). Known-card accuracy ~67-68% is insensitive to representation, but unseen-card accuracy jumps: Features+Meta+Image ~43% on new sets, up to ~55% pretrained, vs ~24% random baseline. Siamese deck/card encoder with triplet loss into a 512-d space; pick = nearest candidate to deck embedding.
- [Predicting Human Card Selection in MTG with Contextual Preference Ranking (Bertram et al., 2021)](https://arxiv.org/pdf/2105.11864) *(paper)* — verify: reachable✅, accurate✅  
  Siamese network with triplet loss frames the pick as 'card p is a better addition to deck C than card n'. Anchor=current deck (count vector), positive/negative=candidate cards; inference picks the candidate with minimal Euclidean distance to the deck embedding. Authors state the method is domain-agnostic for sequential set-addition problems.
- [AI Solutions for Drafting in Magic: the Gathering (Ward et al. / Draftsim, 2020)](https://arxiv.org/pdf/2009.00655) *(paper)* — verify: reachable✅, accurate✅  
  Defines the draft-prediction task and baselines: collection count-vector + pack indicator-vector; NNetBot (3 dense layers, softmax over all 265 cards, logits multiplied by the pack vector to enforce legality) reaches 48.67% top-1 on M19, beating Bayes (43.4%) and heuristic (44.5%). Explicitly names unseen-card / cross-set generalization as future work.
- [Which Heroes to Pick? Learning to Draft in MOBA Games with Neural Networks and Tree Search (JueWuDraft, IEEE ToG 2021)](https://arxiv.org/abs/2012.10171) *(paper)* — verify: reachable✅, accurate✅  
  Supervised win-rate predictor over complete 10-hero lineups + policy/value network guiding PUCT-MCTS over the draft tree, with a long-term value mechanism summing win-rate across future rounds. Neural guidance keeps the large action space (100+ heroes) tractable where minimax is not; optimizes win-rate, not human imitation.
- [Self-Attentive Sequential Recommendation (SASRec, Kang & McAuley, ICDM 2018)](https://www.semanticscholar.org/paper/Self-Attentive-Sequential-Recommendation-Kang-McAuley/97faeefa771e8cc8e55159e2bd03e6f5eef249a8) *(paper)* — verify: reachable✅, accurate✅  
  Stacked self-attention blocks with position embeddings encode the interaction-history context; candidate next-items are scored by dot product with a shared item-embedding matrix (left-to-right next-item prediction). The shared-embedding dot-product head is exactly the 'score a variable candidate set' pattern; swapping IDs for content features enables cold-start.
- [BERT4Rec: Sequential Recommendation with Bidirectional Encoder Representations from Transformer (Sun et al., 2019)](https://arxiv.org/pdf/1904.06690) *(paper)* — verify: reachable✅, accurate✅  
  Bidirectional (masked-item / cloze) self-attention over the interaction sequence; provides a strong self-supervised pretraining objective (predict masked picks) that transfers to draft logs and a context encoder usable with a shared-embedding scoring head.
- [A Flexible Two-Tower Model for Item Cold-Start Recommendation](https://www.researchgate.net/publication/376819594_A_Flexible_Two-tower_Model_for_Item_Cold-start_Recommendation) *(paper)* — verify: reachable✅, accurate✅  
  Two-tower/dual-encoder where the item tower relies on content features rather than learnable IDs, so new items are embeddable and servable immediately without retraining — the canonical cold-start recipe that maps onto unseen-card scoring in MTG.
- [Exploring reinforcement learning approaches for drafting in collectible card games (Hearthstone arena, ScienceDirect)](https://www.sciencedirect.com/science/article/abs/pii/S1875952122000490) *(paper)* — verify: reachable✅, accurate✅  
  Self-play deep-RL for arena deck-building; variants differ in how they encode already-drafted cards when picking the next card — directly the 'how to represent the context pool' design question for MTG, and an objective-grounded (win-rate) alternative to imitation.
